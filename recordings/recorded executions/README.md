Drop `.mp4`, `.webm`, `.mov`, or `.mkv` recordings here.

The Playwright-from-video skill fetches videos from this folder automatically.

```text
recordings/recorded executions/my-flow.mp4
```

Then ask Cursor or Claude Code:

```text
Generate Playwright from recordings/recorded executions/my-flow.mp4
```

Or list what is here:

```bash
npm run generate:frames:list
```
